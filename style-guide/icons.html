Icon adjustment

All four source icons are 512 × 512 pixel images with an opaque background. Use cream #f4f1e8 for the background and green #173e30 for the mark. Edge pixels blend these two colors.

Compare the four icons in one row. Adjust the numbers below each icon. Use the up and down controls or the arrow keys to change a value by one.

On a narrow screen, scroll the icon row horizontally. The original icons remain in use by the tools.

Scale is a percentage of the original symbol. X and Y set its center on the 512-pixel canvas. Larger X values move right. Larger Y values move down. Use whole numbers. Values outside the allowed range are adjusted when you leave the field. Copy the settings before closing or reloading this page.
