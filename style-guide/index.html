volo1st / UI style guide

Draft 01 · for review

One site. One shared language.

A working user interface (UI) style guide for type, controls, and common patterns. Compare the current styles. Then refine the shared draft before changing existing pages.

The draft styles apply only to this guide. Buttons show visual states and do not run app actions. Native fields and disclosures can be used. No input is stored or processed.

08 / Review

Choose the system before migrating.

  1. Choose the fonts and text sizes.
  2. Choose control borders, heights, spacing, and disabled treatment.
  3. Choose notice tones and panel density.
  4. Review long labels, Chinese text, keyboard focus, narrow layouts, and 200 percent zoom.
  5. Approve the draft. Then migrate one page or app at a time.

Source review and the existing repository checks cover this first draft. Browser review remains for the visual iteration. No browser tooling is installed for this package.
