01 / Typography

Serif by default. Sans-serif for controls.

Use one serif family for headings and content. Use sans-serif for interactive controls and their labels. Use monospace for source text and technical values. Inline links keep the surrounding text font.

Use five named sizes and two weights. Reserve the smallest size for fine print. Keep headings regular. Use bold for emphasis, control labels, and subsection headings. Use normal letter spacing.

These are local font stacks. The actual fonts depend on the device. Compare English and Chinese before choosing the final set.

02 / Layout

One centered page width.

The header and content share one container. On desktop, the page stops growing at 48rem. On mobile, the content fits the available width with visible margins on both sides.

Maximum width
48rem
Minimum side space
1–2rem

At the default 16-pixel base size, the maximum is 768 pixels. Minimum side space follows 4 percent of the viewport width, bounded by 1rem and 2rem. Centering leaves more space on wide screens. The gutter token describes each side.

Resize the page to compare desktop and mobile layouts. Sample grids use one column on small screens. Content can wrap without a fixed minimum page width.

The page specimens below use the same shared width as the maintained pages.

Space shows the relationship.

Keep a heading close to its content. Separate paragraphs by 1rem and field groups by 1.5rem. Give sections 2rem of padding on desktop and 1.5rem on mobile.

Use ui-flow for text, ui-stack for field groups, and ui-actions for wrapping action rows. These classes control their direct children's spacing.

04 / Actions

The same button, in each context.

Buttons and single-line fields share a 1-pixel border and common padding. The default minimum height is 2.75rem (44 pixels). Above 650 pixels, a fine pointer with hover uses a compact 2.25rem (36-pixel) minimum. Font size stays the same. Long labels can wrap and increase the height.

Use Tab to compare focus outlines. Hover and press enabled buttons to inspect their styles. Disabled samples remain unavailable. These buttons do not run app actions.

09 / Page headers

One page context. Clear navigation.

Keep breadcrumbs in English. Use the page-title style for reading pages. Keep compact tool headers quiet, with a real page heading available to assistive software.

Use En for English and 中 for Simplified Chinese. Tools use a compact segmented group with a dark selected segment. Reading pages use a quiet En / 中 choice, with plain bold text for the current language and an underlined alternative. Keep both variants to the right of the breadcrumb while space permits.

The current language is disabled because selecting it again has no effect. Its selected appearance remains visible. Language labels stay on one line and use the supporting text size. Both variants retain the compact desktop height, larger touch height, and common focus outline for the alternative language.

Language samples do not translate this guide. Sample titles use level-four headings within the guide. A real page uses a level-one heading.

Consistent breadcrumb row height

Use the same context row with or without a language choice. The shared minimum is 1.75rem for wide screens with a fine pointer and hover, and 2.75rem for touch. Center contents vertically. Longer text can expand the row. These three frames follow the current screen and pointer settings.
