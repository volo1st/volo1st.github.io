    Help

    Practice controls

    Select a preset to replace the arrangement. The tool asks before it replaces your edits.

    A manual tempo change during playback starts at the next bar. A speed-up change starts at a loop boundary.

    The count-in plays before a fresh start. It does not repeat with the loop.

    Chord names are finger shapes. The capo raises the sounding pitch.

    Select a common Swing value. Edit swing: in the arrangement for another value.

    Speed up starts at half of the current tempo, rounded to the nearest 5 BPM. It uses the current tempo as the target.

    Arrangement format

    Use one chord bar and one strum bar for each bar after repeat expansion.

    Use count-in: 0, 1, or 2 after the BPM directive.

    Use tempo-ramp: off after the count-in directive. To increase the tempo, use a value such as tempo-ramp: +5/2/120. This value adds 5 BPM after every 2 completed loops until it reaches 120 BPM.

    Use capo: 0 for no capo. Use a value from 1 through 12 to raise the sounding pitch while you keep the written chord shapes.

    Use swing: off for straight timing. Use a whole number from 50 through 75 to set the first eighth note's share of each beat. Use swing: 67 for an approximate two-to-one triplet feel.

    Use D for a downstroke, U for an upstroke, and - for no strum.

    Add 2, 3, or 4 to limit the string count. A downstroke starts with the lowest-pitched playable string. An upstroke starts with the highest-pitched playable string.

    Add P for palm mute. Add X for a dead strum. Add ! last for an accent.

    Write tokens in this order: direction, string count, articulation, accent. Example: D3P!.

    Use Chord@N for a chord change at slot N. The change occurs before a strum at the same slot.

    Use xN after one bar to repeat that bar N times in total.

    Supported chords:

    A Am Bb Bm C Cm D Dm Em F F#m G Am7 C7 Cmaj7 D7 G7 Cadd9 Dsus4 G5 Am/G C/E D/F# G/B
