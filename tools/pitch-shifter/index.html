About the audio engine

This tool uses Signalsmith Stretch. I selected the processing settings through listening tests with vocals, full mixes, and transient-heavy music.

The tool uses the official cheaper preset. It uses WebAssembly SIMD when available and an equivalent scalar build as a fallback.

Pitch shifting can add audible artifacts, especially with large shifts and exposed vocals. The output keeps the source duration but does not keep source metadata.
