About this tool

Your audio stays in this browser. This tool does not upload the file or send audio over the network.

This tool uses Signalsmith Stretch. I selected the processing settings through listening tests with vocals, full mixes, and transient-heavy music.

Live playback uses the official AudioWorklet interface. File processing uses WebAssembly single instruction, multiple data (SIMD) when available and an equivalent scalar build as a fallback.

MP3 export uses LAME at 320 kbit/s. It can add a short codec delay. WAV keeps the processed audio without another lossy encoding step.

Pitch shifting can create samples outside the output range. The encoder keeps the rendered level and clamps only those samples. Processing statistics show the peak and clipped-sample proportion. The completion status reports when more than 1 percent of samples are clipped.

Pitch shifting can add audible artifacts, especially with large shifts and exposed vocals. Pitch processing keeps the source duration. Exported files do not keep source metadata.
